# Tip Calculator - MLH Builders Week Mini App

A small working tip calculator built during MLH Global Hack Week: Builders Week (Nov 6-12, 2026).

- Single HTML page with JavaScript (`index.html`) - no build step, just open it in a browser.
- Enter bill amount, tip percent and number of people; tip, total and per-person amounts update live as you type.

Built by Mohd Khatab (GitHub: mohdkhatab) as the Challenge 1: Build a Mini App submission for Builders Week.
